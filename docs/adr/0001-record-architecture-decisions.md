# 1. Record architecture decisions

Date: 2026-10-08

## Status

Accepted

## Context

Decisions about this project need to be recorded so their reasons stay clear later, to future contributors and to me.

## Decision

Significant decisions are recorded as Architecture Decision Records in docs/adr/, one file per decision, numbered in order. An accepted ADR is never edited; a changed decision gets a new ADR that supersedes the old one.

## Consequences

Each decision's reasoning is versioned alongside the code. Changing a decision takes a new ADR rather than a quick edit.
